# Data dictionary — normalized per-90 player-season schema

Generated by `src/harmonize/metrics.py`. One row per source × player × league × season in `data/interim/player_seasons.parquet`.

| column | formula | source columns |
|---|---|---|
| `minutes` | sum of minutes_played across a player's league-season rows | asa:minutes_played / fbref:playing_time_min |
| `position` | modal general position for the league-season | asa:general_position / fbref:pos (first listed) |
| `goals_per90` | goals / minutes * 90 | asa:goals / fbref:performance_gls |
| `xgoals_per90` | xgoals / minutes * 90 | asa:xgoals / fbref:expected_xg |
| `xassists_per90` | xassists / minutes * 90 | asa:xassists / fbref:expected_xag |
| `key_passes_per90` | key_passes / minutes * 90 | asa:key_passes (fbref: n/a) |
| `xg_xa_per90` | (xgoals + xassists) / minutes * 90 | asa:xgoals+xassists / fbref:expected_xg+expected_xag |
| `goals_added_raw_per90` | goals_added_raw_total / minutes * 90 — g+ is an action-value framework, NOT xG (see metric_glossary.md) | asa:goals_added_raw_total (fbref: n/a) |
| `goals_added_above_avg_per90` | goals_added_above_avg_total / minutes * 90 | asa:goals_added_above_avg_total (fbref: n/a) |
| `pass_pct_over_expected` | pass_completion_percentage - xpass_completion_percentage (already a rate; NOT per-90 normalized) | asa:xpass endpoint (fbref: n/a) |
| `share_team_touches` | minutes-weighted mean share of team touches (already a rate; NOT per-90 normalized) | asa:xpass endpoint (fbref: n/a) |
